# disableDebuffAndTipped

Source project maintained by aricutiee. Build configuration and default resources are preserved from the IntelliJ project.

## Build

Requires Java 21 and Maven. On Windows, run `mvn verify` from this folder. See the build configuration for the exact Minecraft and dependency versions.

Compiled output, IDE settings, caches, local credentials and runtime data are excluded from Git. No gameplay changes were made as part of publishing this repository.
